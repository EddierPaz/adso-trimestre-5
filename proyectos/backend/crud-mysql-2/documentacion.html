Lógica de Negocio

Consulta con Relaciones (JOIN)

Ejemplo del método listar() en TareaService, el cual obtiene los datos cruzando la tabla de tareas con la de usuarios y categorías.

services/tarea_service.py 
def listar(self):
    cursor = self.db.get_cursor()
    cursor.execute("""
        SELECT t.id, t.titulo, t.descripcion, c.nombre, u.nombre
        FROM tareas t
        INNER JOIN usuarios u ON t.usuario_id = u.id
        INNER JOIN categorias c ON t.categoria_id = c.id
    """)
    return cursor.fetchall()
